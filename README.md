# お金のタイプ診断（GitHub Pages用）

## ファイル構成
- `index.html`
- `style.css`
- `script.js`
- `images/`（6タイプの画像）

## 公開方法
1. このZIPをパソコンで解凍します。
2. GitHubのリポジトリで、古いファイルを削除します。
3. `Add file` → `Upload files` を押します。
4. **解凍後のフォルダそのものではなく、中にある全ファイルと images フォルダをアップロード**します。
5. `Commit changes` を押します。
6. `Settings` → `Pages` を開きます。
7. Sourceを `Deploy from a branch`、Branchを `main`、Folderを `/ (root)` にして保存します。

## 重要
`index.html` は約4KBのテキストファイルです。GitHub上で開くと、先頭に `<!doctype html>` と表示されます。
画像を `index.html` という名前に変更しないでください。
