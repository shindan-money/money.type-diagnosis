# フジナガ版 マネータイプ診断

GitHub Pagesでそのまま公開できる、スマートフォン・パソコン対応の診断サイトです。

## GitHubへのアップロード

ZIPを解凍し、フォルダの中にある次の5項目をリポジトリの一番上へアップロードしてください。

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `images` フォルダ

`fujinaga-money-type-diagnosis` フォルダごとではなく、**フォルダの中身**をアップロードします。

## GitHub Pagesの設定

1. リポジトリ上部の `Settings` を開く
2. 左側の `Pages` を開く
3. `Source` で `Deploy from a branch` を選ぶ
4. Branchを `main`、フォルダを `/ (root)` にする
5. `Save` を押す

数分後、同じPages画面に公開URLが表示されます。
